测速只访问上方路由器，不连接外网测速服务器。测试数据接收后即丢弃，不保存文件。每个方向先预热 1 秒，再显示实际吞吐量（Mbps 与 MB/s）。请保持页面在前台，暂停其他下载和文件传输。

结果反映当前设备与路由器之间的实际 HTTP 传输能力，受 Wi-Fi 信号、有线连接、浏览器及路由器 CPU 性能影响。

这不是宽带外网速度，也不是路由器端口的标称速率；延迟包含 HTTP 请求处理时间。
